# Utility Scripts

| Script | Description |
|---|---|
| `imu_calibrate.py` | Collect bias samples from a node, output `calibration_nodeN.json` |
| `camera_calibrate.py` | OpenCV checkerboard calibration for ArduCAM OV2640 |
| `log_parser.py` | Convert raw binary logs to CSV |
| `csv_to_edgeimpulse.py` | Reformat labeled CSVs for Edge Impulse upload |
